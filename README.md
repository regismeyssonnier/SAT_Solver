# SAT_Solver
3-SAT Solver

# 1. How to compile it ?

Write command:

```bash g++ -std=c++17 -O3 -march=native -mtune=native -funroll-loops -finline-functions -fomit-frame-pointer -ftree-vectorize -ffast-math -fno-stack-protector -pipe -o Solver_3_SAT_Evo Solver_3_SAT_Evo.cpp ```

# 2. What is it exactly ?

Its SAT solver who resolve implemented in the code like TSP, ADD numbers, etc... Look at the code.
